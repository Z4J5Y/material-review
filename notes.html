一条主线（全书灵魂）

成分 + 工艺 → 结构（相 + 组织）→ 性能 → 服役表现

任何一道简答题、综合分析题，都可以套用这条链路作答：先说材料成分，再说加工工艺，再推组织，再推性能，最后落到服役与失效。

两类问题

  • 「是什么」：定义、分类、牌号、工序名称、数字（如 727 ℃、0.77 %C、Cr ≥ 12.8 %）。
  • 「为什么」：结构决定性能、工艺决定组织、缺陷决定失效。

三个层次

  1. 结构层次：原子/分子 → 晶格 → 相 → 组织 → 性能（尺度从几分之一纳米到数十米）。
  2. 材料层次：金属 / 无机非金属 / 高分子 / 复合材料。
  3. 工艺层次：热加工（铸、锻、焊、增材、粉末冶金）+ 冷加工（车铣刨磨钻）。

考试策略

  • 选择题、判断题：抓「数字、定义、对应关系」，本手册的表格就是为此准备的。
  • 简答题：按「定义 + 分类/特点 + 举例」三段式，分点作答，关键词优先。
  • 综合分析：按「现象 → 原理（成分/工艺/组织）→ 措施 → 检验/结论」四段式，务必落到工程。

第 1 章 绪论：材料的基本属性与发展史

1.1 材料是什么

  • 材料定义（工程科学角度）：材料是被赋能的物质。人类通过分离、提纯、合成、改性等操作，赋予物质某种功能与性能，物质才成为材料。
  • 元素—物质—材料：天然存在于地球上的化学元素只有 92 种；有限的元素通过不同组合与存在形态构成物质世界。
  • 三大支柱：材料、能源、信息 是现代社会的三大支柱，而加工制造技术是支撑现代社会运转的基础。
  • 双刃剑：材料的大规模生产与消费带来便利，也造成环境污染、垃圾围城，因此课程单列「材料消费与可持续发展」。

1.4 相与组织（最易混，必考）

  • 相：成分、结构均匀，且与周围有界面分开的一块物质。
  • 固溶体：溶质原子挤进溶剂晶格，如 Mn 溶入 Fe。
  • 化合物：按固定比例结成新格子，如渗碳体 Fe₃C。
  • 组织：显微镜下看到的东西 = 相的种类 + 数量 + 大小 + 形状 + 分布。
  • 典型例子：
  • 珠光体 P：铁素体与渗碳体交替的层片状共析产物（退火态钢的主体，硬度约 HB200）。
  • 马氏体 M：淬火时被「冻结」的过饱和固溶体（硬而脆，可达 HRC60+）。
  • 同一钢块，不同工艺 → 不同组织 → 不同性能：退火（珠光体，软、好切削）→ 淬火（马氏体，硬耐磨）→ 回火（硬度与韧性重新分配）。

1.5 性能提升的三条路径

  1. 改成分：合金化（加 C、Mn、Cr、Ni 等）。
  2. 改工艺：热处理、塑性加工、焊接等。
  3. 改尺度：细化晶粒——唯一能同时提高强度与韧性的途径。

1.6 材料分类

  • 按化学键/组成：金属材料、无机非金属材料（陶瓷、玻璃、水泥）、高分子材料、复合材料。
  • 按用途：结构材料、功能材料。
  • 按状态：单晶、多晶、非晶（玻璃）、薄膜、纤维、粉体。

  • 不锈钢：1912 年英国冶金学家布雷尔利（Brearley）研究枪管钢时发现含铬 12.8 % 的试样不锈；几乎同时美国、德国也有发现；1924 年哈特菲尔德发明奥氏体不锈钢。四大类：奥氏体、铁素体、双相、马氏体。
  • 硬铝：偶然发现的时效硬化铝合金（航空起源）。
  • 永磁材料：从钢厂垃圾—氧化铁皮发展出的铁氧体永磁，性价比最高。
  • 尼龙：学名聚酰胺 PA，杜邦公司卡罗塞斯开发，己二胺 + 己二酸缩聚得尼龙 66；英国同行用芳香族羧酸 + 二元醇缩聚于 1940 年合成涤纶（聚酯纤维）。
  • 复合材料：20 世纪 30 年代，块体玻璃拉成丝后强度大幅提高，热固性聚酯、环氧树脂商业化，玻璃纤维增强聚酯（GFRP） 屈服强度达 300 MPa，超过当时主流低碳钢。

2.3 钢铁的分类

  • 按化学成分：碳素钢（低碳 ≤0.25 %C、中碳 0.25~0.60 %、高碳 >0.60 %）；合金钢（低合金 <5 %、中合金 5~10 %、高合金 >10 % 合金元素总量）。
  • 按冶炼与脱氧：普通质量钢/优质钢/高级优质钢（按 S、P 控制）；沸腾钢（脱氧不完全、成本低、偏析大）与镇静钢（完全脱氧、组织致密、性能均匀、重要构件用）。
  • 按用途：结构钢（用量最大）、工具钢（高硬度高耐磨）、特殊用途钢（不锈钢、耐热钢、耐磨钢、电工钢）。

2.5 钢铁生产全流程（简答必背）

  1. 采矿选矿：磁铁矿 Fe₃O₄、赤铁矿 Fe₂O₃、褐铁矿 Fe₂O₃·3H₂O、菱铁矿 FeCO₃ → 破碎、选矿得精矿粉。
  2. 烧结：矿粉 + 溶剂 + 燃料 + 水 → 多孔块矿（保证高炉透气性）。
  3. 炼焦：多种煤混合炭化 → 焦炭（接近纯碳）；95 % 以上钢铁生产仍用 300 年前 Darby 发明的焦炭炼铁法。
  4. 高炉炼铁：铁矿 + 焦炭 + 石灰石高温还原 → 生铁（铁水）。
  5. 铁水预处理：脱硫、扒渣。
  6. 炼钢：转炉（铁水 + 10~15 % 废钢，吹氧氧化 C、Si、Mn，靠铁水自身热量，不加燃料）；电炉（废钢 + 电能）。
  7. 炉外精炼（二次精炼）：惰性/还原气氛中脱气、脱氧、脱硫、去夹杂。
  8. 连铸：钢水连续浇成坯（已基本取代铸锭，仅大型铸件仍用钢锭）。
  9. 热成形：铸造、锻造、轧制（占塑性加工 90 % 以上）、焊接；再机械加工与防护（热镀锌等）。
记忆链：矿 → 烧 → 焦 → 铁 → 预 → 钢 → 精 → 铸 → 形 → 机加 → 防护。

2.6 加工与防护

  • 铸造：金属液态成形，最早的金属热加工工艺；流程为液体金属 → 充型 → 凝固收缩。
  • 锻造：8 万吨级锻压机（世界最大）。
  • 轧制：坯料通过旋转轧辊间隙受压变形；冷轧在再结晶温度以下、热轧在以上；TMCP（控轧控冷）通过控制加热温度、轧制过程与冷却条件提高强韧性；无缝钢管的斜轧法（Mannesmann 法）：斜轧辊穿孔 + 芯棒延伸。
  • 焊接：加热/高温/高压连接金属，分熔焊、压焊、钎焊；焊接机器人是高度自动化标志。
  • 机械加工：车、铣、刨、磨、钻；数控（CNC）源于航空复杂型面零件需求。
  • 腐蚀与防护：化学腐蚀与电化学腐蚀，本质都是金属原子氧化为阳离子；锈蚀最常见；措施有热镀锌、涂装、阴极保护等。

3.2 从单体到制品：三段式

3.4 橡胶

  • 定义：具有高弹性的高分子材料，玻璃化转变温度低于使用温度，受力可大变形、卸力能恢复。
  • 分类：
  • 按来源：天然橡胶、合成橡胶。
  • 按用途：通用橡胶、特种橡胶。
  • 按交联性：热塑性橡胶（TPE）、硫化橡胶。
  • 天然橡胶制取：三叶橡胶树割胶 → 胶乳收集（加氨保存）→ 加醋酸凝固 → 压片、洗涤、脱水、干燥。

  • 通用合成橡胶：丁苯胶、顺丁胶、异戊胶、丁腈胶（耐油）、氯丁胶、丁基胶（气密性好，内胎）、乙丙胶、三元乙丙胶。
  • 特种橡胶：硅橡胶（宽温域）、氟橡胶（主链饱和碳链 + 大量 C—F 键，180 ℃ 长期工作，耐化学）、聚氨酯橡胶。

  • 橡胶制品工艺：生胶 + 配合剂（硫化剂、促进剂、活性剂、补强剂、防老剂）→ 塑炼混炼 → 成型 → 硫化（温度、时间、压力三要素）。

第 4 章 无机材料（陶瓷、水泥、玻璃）

4.1 分类与特点

  • 传统无机非金属材料：以天然硅酸盐矿物（黏土、石英、钾长石、钠长石）为原料，经高温窑烧而成，又称窑业材料（陶瓷、玻璃、水泥、耐火材料）。
  • 新型无机非金属材料：用氧化物、氮化物、碳化物、硼化物、硫化物、硅化物等经特殊工艺制成，包括特种陶瓷、特种玻璃、特种水泥等。
  • 分类维度：按成分（硅酸盐、氧化物、碳化物…）、按形态（块体、薄膜、纤维、粉体）、按结构（单晶、多晶、玻璃、无定形、复合材料）、按工艺（烧结成材、湿法合成、涂镀、水硬材料）。
  • 六大特点：① 化学组成为无机化合物或非金属单质；② 形态多样（多晶/单晶/非晶/薄膜/纤维）；③ 原子间结合力为离子键、共价键或混合键，故硬度高、脆、绝缘；④ 制备要求高纯、高细原料；⑤ 性能多样（高硬度、耐腐蚀、抗氧化）；⑥ 多需高温制备。

4.2 陶瓷简史与分类

  • 粗陶（新石器时代早期，7000~8000 年前）→ 彩陶（仰韶，4000~6000 年前）→ 黑陶（龙山，轮制技术）→ 釉陶（商周，釉料）→ 粗瓷/炻器（汉代）→ 隋唐「南青北白」→ 宋代五大名窑（定、汝、官、哥、钧）→ 元代青花（瓷石 + 高岭土二元配方）→ 明清景德镇鼎盛。
  • 陶器 / 炻器 / 瓷器（必背）：
类别吸水率特征
陶器10 % > 吸水率 > 3 %多孔、强度低、断面粗

  • 狭义陶瓷：天然或人工合成的粉状化合物经成形和高温烧结制成的、由金属与非金属元素无机化合物构成的多晶材料。
  • 广义陶瓷：以无机非金属物质为主的固体材料及其制造与应用的科学和技术。

4.3 陶瓷生产工艺（简答必背）

  1. 原料配制：高岭土（黏土）、石英、长石三大类；经拣选、风化、粉碎、除杂、配料、混炼（湿法球磨、过筛除铁、陈腐）。
  2. 坯料成型：
  • 可塑成型：旋压、滚压、拉坯、雕塑印坯（回转体、手工件）。
  • 注浆成型：泥浆注入石膏模，靠吸水沉积成坯；适合薄壁、体积较大、尺寸精度要求不高的器物（卫生洁具、花瓶）；缺点是劳动强度大、不易自动化、收缩变形大。
  • 干压成型：干粉在模中压制成形；产量大、缺陷少、易机械化，适合形状简单的小型坯体。
  • 坯料三种状态：注浆用泥浆、可塑成型用泥团（泥段）、干压用粉料。
  1. 坯体干燥：自然干燥与人工（强制）干燥；方法有对流、电热、高频、微波（915 MHz 与 2450 MHz）；微波可使坯体内加热，几分钟完成、不易变形开裂、便于联动生产。
  2. 窑炉烧结：脱水、分解、氧化、液相烧结、晶粒长大、气孔排除、体积收缩、强度提高；控制温度曲线、气氛与冷却制度。
  3. 装饰上釉、加工、检验包装。

4.4 水泥

  • 定义：狭义水泥专指现代水泥——具有水硬性的胶凝材料（既能在空气中硬化，也能在水中硬化）。
  • 发展：1886 年澳门青洲岛第一家水泥厂；1889 年唐山建厂；我国新型干法水泥起步于 20 世纪 70 年代，80 年代成套引进，90 年代形成规模。
  • 分类：按用途性能（通用、专用、特种）；按组成（硅酸盐、铝酸盐、氟铝酸盐、硫铝酸盐、铁铝酸盐系列）。
  • 硅酸盐水泥生产三阶段：生料制备（石灰石 + 黏土 + 铁粉混合磨细）→ 熟料煅烧（1400~1450 ℃） → 水泥粉磨（熟料 + 石膏 + 混合材）。
  • 环保：余热发电、协同处置固废、替代燃料。
  • 地位：中国建材集团熟料产能 5.3 亿吨、商混 4.6 亿立方米，均居世界第一。

4.5 玻璃

  • 原料：石英砂、纯碱、石灰石、长石（+ 澄清剂、着色剂、碎玻璃）。
  • 四大特性：各向同性、无固定熔点（软化温度范围）、亚稳态（非晶态）、性质可调（通过成分与再加工大幅调整）。
  • 生产工艺（四步，必背）：
  1. 配料：按料方称量混合。
  2. 熔制：1400~1600 ℃，经历硅酸盐形成、玻璃形成、澄清、均化、冷却。
  3. 成形：在黏度—温度窗口内由黏性液态 → 可塑态 → 脆性固态；人工吹制/拉制，机械压制/压延/浇铸/离心浇铸/烧结。
  4. 退火：缓慢冷却消除热应力，防止炸裂、提高强度与热稳定性。
  • 品种：普通玻璃（高温易软化）、石英玻璃（膨胀系数小、耐酸碱、强度大、滤光）、光学玻璃（透光、折光、色散）、玻璃纤维（耐腐蚀、耐高温、不导电、隔热，用于玻璃钢、宇航服、光导）、钢化玻璃（表面压应力，耐冲击，碎后颗粒）、有色玻璃。
  • 产业：福耀为全球第二大、中国第一大汽车玻璃厂商（市占率 63 %）。

第 6 章 典型热加工工艺（一）：铸造

6.1 定义与地位

  • 铸造（Casting）：将熔化好的液态金属倒入具有特定形状空腔的耐火模具，凝固成形后打破或拆开模具取出零件——又称金属液态成形。
  • 工艺流程：液体金属 → 充型 → 凝固收缩 → 铸件。
  • 人类最早掌握的金属热加工工艺；优势是可做复杂形状（含内腔）与大型件、成本低、适应性强。

第 7 章 典型热加工工艺（二）：锻压与板料成形

7.1 塑性变形基础

  • 晶格水平的原子运动：滑移与孪生。
  • 塑性变形：永久变形，超出弹性范围；可导致组织变化、再结晶与晶粒细化，还能消除内部缺陷、破碎夹杂物，改善力学性能。
  • 加工硬化：冷变形使位错密度增加、相互缠结，强度硬度升高、塑性下降。
  • 回复：较低温退火，空位与位错重排、异号位错相消，储存能下降，晶粒形状不变。
  • 再结晶：更高温度下新晶粒形核长大，变形组织被无畸变等轴晶取代，硬化消除、塑性恢复。
  • 晶粒长大：再结晶后继续升温/保温，晶粒粗化、性能下降。

7.2 热作与冷作（必背对比）

划分依据：变形温度相对于材料再结晶温度。

热作冷作
优点可反复大变形、无加工硬化；高温延展性好；设备压力低；可得等轴细晶显著提高强度硬度；表面无氧化物、光洁；尺寸精度高；夹持搬运方便
缺点高温脆性材料不能热作；氧化使表面差；膨胀收缩难控尺寸；大件搬运难单次变形量小、多道次；设备载荷大、成本高；需中间退火；低温脆性材料不能冷作
  • 温度与晶粒：超过再结晶温度后晶粒持续长大；加热后不变形直接冷却晶粒粗大；热加工在略高于再结晶温度完成时晶粒最细。

7.3 轧制

  • 原理：坯料通过一对旋转轧辊的间隙，受压缩而厚度减小、长度增加；钢铁塑性加工 90 % 以上靠轧制。
  • 产品：钢板、钢带、螺纹钢、角钢、槽钢、H 型钢、无缝钢管、线材。
  • 孔型（roll pass）：轧辊上的沟槽，决定断面形状。开坯孔型有箱型（大截面、压缩率较低）、菱-方（接触面小、轧辊强度低）、椭-方（压缩率大、宽度方向变形均匀性差）。
  • 压缩率（draught）：每道厚度压下量比例，需合理分配。
  • 无缝钢管：1885 年曼内斯曼兄弟提出斜轧穿孔，斯蒂费尔加固定芯棒，形成桶型二辊斜轧法——圆棒受循环压缩应力，中心形成空腔并扩大，芯棒整形。
  • TMCP（控轧控冷）：控制加热温度、轧制过程与冷却条件提高强韧性（加热→轧制→层流冷却→卷取）。
  • 冷轧 vs 热轧：冷轧在再结晶温度以下，表面好、精度高、有加工硬化；热轧在以上，效率高、成本低。

7.4 锻造

  • 定义：将金属加热后施加外力使其塑性成形；人类最古老的金属加工工艺之一（铜器时代已有）。
  • 两种基本操作：拔长（减小截面积、增加长度）、镦粗（减小长度、增加截面积）。
  • 自由锻：无需专用模具，成本低，适合单件小批、大件、试制；精度低、余量大。
  • 机器锻造：气动/液压锻锤，镦粗最常见。
  • 落锤模锻（闭式模具）：反复锤击充满型腔，典型道次：充型、挤压飞边、弯曲、压实，最后切除飞边；精度高、生产率高、适合大批量。
  • 纤维流线（grain flow）：模锻使流线沿零件轮廓连续分布，锻合内部缺陷、细化晶粒，显著提高疲劳强度与冲击韧性（曲轴、连杆、齿轮）。

7.5 挤压

  • 原理：金属在封闭型腔内仅通过一个开口流出，得到与出口一致的截面（类似挤牙膏）。
  • 分类：热挤压/冷挤压；正向挤压（金属流动与冲头同向，坯料与筒壁有摩擦，需润滑：低温油 + 石墨、高温熔融玻璃）、反向挤压（模具在冲头，金属反向流出，无筒壁摩擦、压力低、组织均匀）；冲挤、液压挤压。
  • 特点：可制任意长度等截面件；模具小、可做复杂甚至中空截面；减径量大；脆性材料也可挤压。
  • 空心型材：需组合模——上模分流桥把坯料劈成几股，在焊合室重新焊合，再由模芯与下模孔间隙挤出，形成内外轮廓（铝型材）。

7.6 板料成形（钣金/冲压）

  • 现代钣金加工以冲压为主（汽车覆盖件、家电外壳）。
  • 回弹：卸载后弹性部分恢复、塑性部分保留；回弹量是材料基本性能参数，需在模具设计中补偿。
  • 冲裁间隙：C = 0.0032 · t · τ^(1/2)（t 板厚 mm，τ 剪切应力）；间隙过大 → 塌角与毛刺大；过小 → 冲裁力与模具磨损增大。
  • 冲模角度：一般 0.25°~0.75°，厚而软的材料取大值。
  • 落料 vs 冲孔：落料冲下的是零件、周边是废料；冲孔冲出的是废料、带孔板料是零件。
  • 拼板焊接（TWB）：不同厚度/强度钢板对接焊后冲压，实现按需加强、减重（激光焊/电子束焊/搅拌摩擦焊）。
  • 一体化压铸：把白车身数百零件、数千焊点合并为一次成形（特斯拉等），挑战是免热处理高强铸造铝合金、超大压铸机与模具、废品率与维修成本。

第 8 章 典型热加工工艺（三）：焊接

8.1 定义与分类（必背）

  • 焊接：一个冶金连接过程——待连接工件的两个界面被加热到熔点以上并共同凝固（或加压使原子接近到形成金属键），形成永久连接。
  • 传统分类：熔化焊（母材熔化）、压力焊（加压，不熔化或局部熔化）、钎焊（母材不熔化、钎料熔化）。
  • 新分类：电弧焊、固相焊、电阻焊、钎焊、高能束焊。
  • 连接方式对比：焊接（冶金结合）、胶接（Adhesive bonding，靠胶粘剂）、机械连接（螺栓、铆接）。

8.3 焊接应力与变形

  • 产生原因：局部、快速、不均匀加热与冷却；焊缝区受周围冷金属约束产生塑性变形，冷却收缩受阻形成拉应力；相变（马氏体）伴随体积变化产生组织应力。
  • 危害：降低刚度与稳定性、引起尺寸失稳、促进应力腐蚀与疲劳、降低承载能力。
  • 控制（减小）：合理设计接头（减少焊缝、避免应力集中）；合理焊接顺序（对称、分段退焊）；反变形法；刚性固定；小线能量、多层多道；预热与缓冷。
  • 消除：去应力退火（550~650 ℃）；振动时效；锤击、喷丸、超声冲击；机械拉伸法。
  • 矫正：机械矫正（压力机、锤击）、火焰矫正。
  • 线能量 E = U·I/v：越大 → HAZ 越宽、晶粒越粗、韧性越低；过小 → 淬硬与冷裂纹风险。

8.5 焊接热影响区（HAZ）

  • 定义：焊缝两侧母材受焊接热循环作用而发生组织与性能变化的区域；宽度随方法与热输入而变（电子束/激光最窄，气焊最宽）。
  • 分区：熔合区 → 过热区（晶粒粗大、韧性差）→ 正火区（细晶，性能最好）→ 不完全重结晶区 → 回火软化区（调质钢、冷作材料）。
  • 为什么是薄弱环节：组织性能不均匀、晶粒粗化、可能形成淬硬马氏体或软化带，裂纹常起源于此。
  • 改善：控制线能量、预热/后热、低碳当量材料、焊后热处理、高能束焊。

附录 C：答题模板

简答题（4 步）

  1. 定义：一句话说清是什么。
  2. 分类/特点：分 2~4 点，每点一个关键词。
  3. 例子：给 1~2 个具体材料或工艺。
  4. 小结：一句工程意义（为什么重要）。

综合分析题（5 步）

  1. 读题定位：这是什么材料？什么工艺？什么失效模式？
  2. 原理：用「成分 + 工艺 → 结构 → 性能」解释现象，必要时写公式（相图温度、E=UI/v、C=0.0032t√τ、Q=I²Rt）。
  3. 方案：给出具体工艺路线或材料选择，说明理由（对比 2~3 个方案）。
  4. 控制：列出缺陷/风险的防止措施（工艺参数、检测）。
  5. 结论：回到服役与经济性，点明「材料—工艺—结构—性能」的闭环。

万能句式

  • 「该现象的本质是……，其组织为……，因此性能表现为……」
  • 「从工艺角度看，可通过……控制……，从而避免……」
  • 「需通过……检测验证，确保……满足服役要求。」
